# Dokumentasi Website ULT Unpad

Folder ini berisi dokumen operasional dan template impor yang mengikuti fitur aplikasi terbaru.

- `admin-guide.docx`: panduan lengkap dari sudut pandang admin, termasuk CRUD, publikasi, tombol kontak, survei, keamanan, troubleshooting, dan impor CSV.
- `content-inventory.docx`: inventori halaman, komponen, sumber data, daftar konten database lokal, pemilik pembaruan, dan celah pengembangan.
- `service-import-template.csv`: template impor layanan dengan konten bilingual dan maksimal tiga tombol kontak.
- `article-import-template.csv`: template impor artikel bilingual dengan SEO dan tombol eksternal opsional.
- `faq-import-template.csv`: template impor FAQ bilingual dengan kategori, sasaran, urutan, dan tombol eksternal opsional.
- `perbandingan-wordpress-vs-laravel-filament-ult.docx`: kajian perbandingan platform.

Gunakan template CSV tanpa mengubah nama header. Penjelasan setiap kolom terdapat di `admin-guide.docx`.
